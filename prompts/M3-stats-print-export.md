## 任务

1. **F07 提醒**  
   - 类型：`fixed_date` / `after_receive_days` / `before_festival_days`。  
   - UI：即将 | 逾期；完成、snooze、删除。  
   - Tauri notification 插件；帮助文案：「退出应用后不保证通知」。  
   - 记一笔开关创建的提醒出现在列表。  

2. **F08 节日**  
   - 内置+自定义 CRUD；筛选往来；跳转打印。  

3. **F13 统计页**（左栏独立）  
   - 筛选：年份（默认今年）、成员、关系标签。  
   - 摘要卡：今年收、支、净、笔数、当前待还人数。  
   - 图：收礼vs送礼柱；月净额折线/面积；关系标签环图。  
   - 「数据表」聚合行；色觉友好（勿只靠红绿）。  
   - 与往来同年筛选汇总 **误差 0**（写对账测试或调试断言）。  

4. **F14 年度人情报告**  
   - 按钮在统计页：「生成 YYYY 年人情报告」。  
   - 章节：封面、总览、Top5（收/送/净待还向）、事由节日分布、待还摘要、页脚个人备忘声明。  
   - 应用内多页预览；导出/打印 PDF（可用打印 CSS 或 pdf 库）。  
   - 无数据空态不崩。  

5. **F09 + F20 打印**  
   - 三模板：待还清单、按人汇总、时间明细。  
   - 金额 **中文大写**（纯函数 + 单测：0、10.5、200、800、1000、10000 等）。  
   - 可选第四模板：**竖排传统礼簿**。  
   - 系统打印对话框 + 另存 PDF。  

6. **F10 导入导出**  
   - CSV 列见 PRD §12。  
   - 导入：映射预览、同名策略提示。  
   - 完整备份（zip/单文件含 DB 或 JSON dump）；恢复前强警告。  

7. **F18 批量粘贴**  
   - 入口：往来或 ⌘/Ctrl+Shift+V。  
   - 解析 `张三 800` / `李四 500 结婚` / `王五 收礼 1000 满月`。  
   - 预览表确认；坏行标红可跳过；写入后刷新。  

8. **F11 设置（接线）**  
   - PIN（hash 存 settings；启动可要求解锁——实现简单挑战即可）。  
   - 农历、减少动效、**实验性 3D 开关（仅存 settings，M4 再接 three）**、关怀模式大字号（根 class 放大字号行高）、回礼建议、回收天数、关于。
