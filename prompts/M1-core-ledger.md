# M1 · 记账闭环

**目标**：账本/成员/记一笔抽屉/往来列表真正可用；默认 CSS/2D 动效；软删基础。

**前置**：M0 完成。精读 PRD F01–F04、F19 字段、§2.5 动效。

**完成后**：commit → **自动执行** `prompts/M2-contacts-reminders.md`。

---

## 任务

1. **F01 账本**  
   - 侧栏下拉：列表、切换、新建（名必填）、重命名、删除（二次确认，至少留 1 本）。  
   - 切换 → 全局 `book_id` context → 各页 refetch。  

2. **F02 成员**  
   - 设置页 CRUD；「我」不可删可改名。  
   - 删除前查 transactions 引用。  

3. **关系标签**  
   - 设置可增删改自定义；系统四项可改名策略自定但勿无种子导致空。  
   - 联系人/记一笔可绑 `relation_tag_id`。  

4. **F03 记一笔抽屉（完整）**  
   - 字段见 PRD 表：联系人（输入搜；暂无拼音可先 substring，M2 补 F15）、类型、金额、快选 chips **200/500/800/1000**、日期+**农历旁注**、事由、节日标签、成员默认「我」、支付方式、礼品、备注、「创建还礼提醒」。  
   - 校验：金额 > 0；联系人非空。  
   - 保存：插入 `transactions`（`amount_cents`）；可选写 `reminders`；关抽屉；toast；列表首行更新。  
   - 「保存并继续」：清空金额/事由，保留联系人与类型。  
   - Esc / 点遮罩：脏则确认。  
   - 快捷键 ⌘/Ctrl+N 打开，⌘/Ctrl+S 保存。  

5. **农历**  
   - 仅 UI 换算；设置「农历显示」默认开，关则隐藏旁注。  

6. **F04 往来**  
   - Tab 全部|收礼|送礼；表格列对齐 style-01；金额着色千分位。  
   - 分页或虚拟滚动；搜索（名/事由）。  
   - 行：编辑（开抽屉）、删除 → `deleted_at`（短时撤销条可选）。  
   - 右栏三卡：本月收/支、今年收/支、概览（笔数/待还可先粗算或 M2 精确）。  

7. **动效 §2.5**  
   - 保存成功：in → 绿脉冲 + `+¥` 飞入；out → 红脉冲 + `−¥`。  
   - 设置「减少动效」；监听 `prefers-reduced-motion`。  
   - **不要**接入 three。  

8. **单测/工具**  
   - 金额元↔分转换纯函数单测。
